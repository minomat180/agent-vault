# Contributing

This is a personal Linux port of [isaaclins/pi-vault](https://github.com/isaaclins/pi-vault),
adapted from macOS Keychain to freedesktop Secret Service. Not maintained as a
general-purpose open source project — issues and PRs are welcome, but may sit
unaddressed.

Read the "Status: not a security boundary yet" section of the README before
relying on this for anything sensitive; that caveat is the most important
thing in the repo.
